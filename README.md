# callmissed-docs

Public documentation for the [CallMissed API](https://docs.callmissed.com) — maintained automatically by CI from the main monorepo.

> **Do not edit files in `docs/` manually.** They are generated by the [`sync-docs-to-context7`](https://github.com/CallMissed/CallMissed/blob/main/.github/workflows/sync-docs-to-context7.yml) workflow from the MDX tree at `apps/docs/content/docs/**` in the monorepo, and any manual edits will be overwritten on the next sync.

## Structure

```
docs/
  README.md          # Navigation index, grouped by section
  introduction.md
  quickstart.md
  mcp-server.md
  models.md
  chat-completion.md
  ... (one file per doc page)
```

Each page carries `title`, `description`, `slug`, and `breadcrumb` frontmatter.
The `breadcrumb` is the section title from the page's `meta.json` group.

## Context7

This repo is registered on [Context7](https://context7.com) under `/callmissed/callmissed-docs`.
Documentation is refreshed automatically on every merge to `main`.

## Usage (AI coding assistants)

```
use context7
```

or reference the library ID `/callmissed/callmissed-docs` directly in Context7-enabled tools.
